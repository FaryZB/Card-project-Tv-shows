# My Favorite TV Shows

A responsive TV show card gallery created as part of my Hyper Island Frontend Development course.

## Built With

- HTML
- CSS
- Flexbox
- CSS Grid
- Responsive design
- Media queries

## Features

- Responsive card gallery
- Netflix-inspired dark design
- Hover animations
- Responsive typography using clamp()
- CSS Grid layout
- Mobile-friendly single-column layout
